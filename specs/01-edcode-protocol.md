# OpenSpec 01: 传奇 6-Bit 编码与网络封包协议规范

## 1. 规范定位
本规范定义客户端与 OpenMir2 服务端（LoginGate / GameGate）之间的基础二进制编解码与网络数据包封包标准。所有实现必须严格遵循本规范，以保证与 OpenMir2 服务端及 Delphi 客户端的二进制兼容性。

---

## 2. 字符集与底层编码

- **传输字符编码**：必须全局强制采用 **GBK (代码页 936)**。
- 禁止直接使用 UTF-8，否则角色名、中文对话及长度对齐将出现致命错位。

---

## 3. 6-Bit 核心编解码算法 (EDCode)

### 3.1 编码数学原理 (`EncodeBuf`)
传奇 6-bit 编码是一种特定变种的 ASCII 可打印字符序列化算法：
1. **掩码与基数**：
   - 异或掩码：`Seed = 0xAC` (172)
   - 基数偏移：`Base = 0x3C` (60, ASCII 字符 `'<'`)
2. **字节扩展比**：
   - 每 3 个原始字节被编码为 4 个 ASCII 字符（4:3 扩展比）。
   - 剩余 1 字节时编码为 2 字符；剩余 2 字节时编码为 3 字符。
3. **算法流程（逐字节）**：
   - 对原始字节 `b` 执行 `c = b ^ Seed`。
   - 拆解高低位，加上 `Base`，映射至 `[0x3C, 0x7B]` 的安全可打印 ASCII 范围。

### 3.2 解码数学原理 (`DecodeBuf`)
- 读取可打印字符，减去 `Base` (0x3C)。
- 恢复 6-bit 片段并拼装回 8-bit 字节。
- 对每个重组字节异或 `Seed` (0xAC) 得到原始数据。

## 4. 默认消息包头结构 (`TDefaultMessage` / `TCmdPack`)

每个标准控制包的核心包头长度固定为 **12 字节 (packed)**：

| 偏移量 | 字段名 (Field) | 类型 (Type) | 长度 (Bytes) | 含义与说明 |
| :---: | :--- | :--- | :---: | :--- |
| `0x00` | `Recog` (UID) | `int32` (有符号整型) | 4 | 实体标识、对象索引或随机请求号 |
| `0x04` | `Ident` (Cmd) | `uint16` (字) | 2 | 协议命令 ID (如 CM_QUERYCHR, SM_QUERYCHR) |
| `0x06` | `Param` (X) | `uint16` (字) | 2 | 参数1 / 坐标 X |
| `0x08` | `Tag` (Y) | `uint16` (字) | 2 | 参数2 / 坐标 Y |
| `0x0A` | `Series` (Direct) | `uint16` (字) | 2 | 参数3 / 朝向或附加标志 |

> **关键推论**：12 字节经过 6-bit 编码后，长度恒为 `(12 / 3) * 4 = 16` 个 ASCII 字符。

---

## 5. 网络封包帧格式 (Framing)

TCP 字节流中的逻辑包以特定的分界符包裹：

```
+---+----------------------+--------------------------+---+
| # | Encoded Header (16B) | Encoded Body / Data (var)| ! |
+---+----------------------+--------------------------+---+
```

- **帧起始符**：`#` (`0x23`)
- **包头部分**：16 字节 ASCII 字符串，解码后得到 12 字节的 `TDefaultMessage`。
- **附带数据 (Payload)**：可选附加串（例如登录凭据、角色名等，通常使用 6-bit 或 `/` 分隔参数）。
- **帧结束符**：`!` (`0x21`)
- **粘包处理**：客户端收到 TCP 流后，应以 `!` 截断并抛出完整帧；若包含换行符（`\r`, `\n`）应予以丢弃。

## 6. 标准测试用例向量 (Test Vectors)

用于单元测试验证任何语言实现的正确性：

### 用例 1：全零包头验证
- **输入 `TDefaultMessage`**：
  `Recog = 0, Ident = 0, Param = 0, Tag = 0, Series = 0` (12 字节全是 0x00)
- **异或 Seed 后字节流**：
  `[0xAC, 0xAC, 0xAC, ...]` (12 个 0xAC)
- **期望 6-bit 编码输出 (16 字符)**：
  严格对齐 Delphi `EncodeMessage` 结果。
